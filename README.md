# Сайт Евгения Куницкого

Персональный сайт-визитка управляющего ГК «ТрансСтрой Девелопмент» (TSD Group).

Одностраничник с 3D-анимацией на первом экране, скролл-анимациями по всем
секциям и четырьмя языками (RU / EN / 中文 / العربية, включая RTL).

## Запуск

```bash
npm install
npm run dev        # разработка, http://localhost:3000
npm run build      # production-сборка в папку out/
```

Сборка статическая (`output: 'export'`) — в `out/` лежат обычные файлы,
их можно положить на любой хостинг. Node.js на сервере не нужен.

## Вступительная анимация

Первый экран — сцена на WebGL. Порядок кадров:

1. проступает сетка чертежа;
2. в грунт уходят сваи (фундамент в вечной мерзлоте);
3. поднимаются каркасы зданий;
4. объёмы заполняются, зажигаются окна;
5. камера отъезжает, начинается снег.

Первые ~4,6 секунды сцена играет сама, страница в это время заблокирована,
есть кнопка «Пропустить». Дальше анимацией управляет скролл.

Разметка фаз — в `src/components/hero/heroState.ts`, маршрут камеры —
в `src/components/hero/CameraRig.tsx` (правится по ключевым кадрам).

### Производительность

Бюджет сцены выбирается по устройству (`src/lib/useDevice.ts`):

| | телефон / слабое железо | десктоп |
|---|---|---|
| зданий | 90 | 190 |
| снежинок | 900 | 3200 |
| pixel ratio | до 1.5 | до 2 |
| сглаживание | выкл | вкл |

При системной настройке «уменьшить движение» вступление пропускается
и показывается финальный кадр.

Three.js грузится отдельным чанком, пока на экране прелоадер: стартовый
бандл — 167 КБ вместо 409 КБ.

## Контент

Все тексты — в `src/content/{ru,en,zh,ar}.ts`, структура задана типом
`Content` в `src/content/types.ts`. Вёрстка текстов не содержит: чтобы
позже подключить админку, менять компоненты не придётся.

Добавляете поле — добавьте его в `types.ts`, тогда TypeScript сам
покажет, в каких языках его не хватает.

## Фотографии

Сейчас стоят снимки городов присутствия с Викисклада (свободные лицензии) —
как временная замена до реальных фото объектов.

Новые фото кладутся в `public/images/` и ужимаются скриптом:

```bash
node scripts/prepare-images.mjs   # 1600px + WebP, исходники удаляются
```

Скрипт сжал текущий набор с 11 МБ до 946 КБ.

## Проверка вёрстки

```bash
npx serve out -l 4173
node scripts/shoot.mjs http://localhost:4173/ /tmp/shots
```

Снимает экраны на десктопе и телефоне в пяти точках прокрутки героя и на
каждой секции. 3D-сцену тестами не покроешь — «поехавшую» камеру или
невидимый текст видно только на картинке.

## Структура

```
src/
  app/            layout, страница, глобальные стили, favicon
  content/        тексты на 4 языках + ссылки
  lib/            i18n, определение устройства
  components/
    hero/         3D-сцена: город, сваи, сетка, снег, камера
    sections/     секции страницы
    ui/           переиспользуемые блоки (Reveal, SectionHead)
scripts/          подготовка картинок, скриншоты
```
